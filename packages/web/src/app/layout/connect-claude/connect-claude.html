Connect Claude

cv-kit gives Claude tools to list, read and write your CVs. Claude starts the server itself through Docker, so keep Docker Desktop running.

Claude Code

Open this project folder in Claude Code. It finds the cv-kit server in .mcp.json and asks once to enable it.

Claude Desktop

Paste this prompt into Claude Code: it can edit files on this Mac and sets everything up. The Claude Desktop chat cannot change its own config.

Set up manually
  1. Open Settings → Developer → Edit Config.
  2. Add the block below inside the file's outer {{ '{ }' }}, next to what is already there, separated by a comma. If "mcpServers" exists, add just the "cv-kit" entry to it.
  3. Replace {{ dockerPlaceholder }} with the output of which docker. @if (!projectDir()) { Replace {{ projectPlaceholder }} with this project's folder. }
  4. Quit Claude Desktop (⌘Q) and open it again.
