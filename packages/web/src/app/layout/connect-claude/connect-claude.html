Claude Code

Open this project folder in Claude Code. It finds the cv-kit server in .mcp.json and asks once to enable it.

Claude Desktop

Download extension
  1. Open cv-kit.mcpb from Downloads, or drag it into Settings → Extensions in Claude Desktop.
  2. Check the project folder Claude Desktop asks for, and install.
Set up with Claude Code

Paste this prompt into Claude Code in a terminal: it can edit files on this Mac and sets everything up. The Claude Desktop chat cannot change its own config, and the Code tab of Claude Desktop closes with the app, which has to quit for the change to stick.

Set up manually
  1. Open Settings → Developer → Edit Config to find the file, and open it in an editor.
  2. Quit Claude Desktop (⌘Q) before editing: while it runs, it rewrites the file and drops new entries.
  3. Add the block below inside the file's outer {{ '{ }' }}, next to what is already there, separated by a comma. If "mcpServers" exists, add just the "cv-kit" entry to it.
